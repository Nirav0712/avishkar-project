# Avishkar Realty

Official website and property portal for [Avishkar Realty](https://www.avishkarrealty.in/).

## Project Overview
Avishkar Realty is a modern real estate platform built with Next.js, React, and Tailwind CSS. It provides property discovery, featured projects, developer partnerships, client testimonials, and an administrative dashboard for managing property listings and inquiries.

## Features
- **Property Discovery**: Search and filter properties by area, type (Apartments, Bungalows, Commercial, Plots), and status.
- **Project Showcases**: Detailed showcases of current and completed residential and commercial projects.
- **Admin Dashboard**: Secure management dashboard for properties and inquiries.
- **Responsive Design**: Optimized for mobile, tablet, and desktop experiences.
- **Interactive UI**: Clean modern design with smooth animations and direct contact options (WhatsApp & Call integrations).

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
